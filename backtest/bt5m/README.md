# 5분봉 백테스트 1차 — 김프(빗썸 × Binance)와 USDT 웃돈 (2026-10-15)

실거래 봇(`kimchi-bot/src/strategy.js`)·페이퍼 봇(`src/paper/usdt.js`) 규칙을 그대로 옮겨 2020-01부터 5분봉으로 돌렸다.
자료는 `data/`(약 830MB, 저장소에 넣지 않음)에 받는다: `node universe.js` → `node fetch_bithumb.js 120 4` (약 70분) · `node fetch_binance.js 120 6` (약 30분).

- 첫 줄의 2025·26년 이익은 빗썸 소형 종목의 «마지막 체결가가 묵어 생긴 가짜 하락»에서 나왔다(상위 기여 OGN·RLC·MET·GTC). 체결이 없는 봉에서는 사고팔지 못하게 하면 사라진다.
- 2024년부터는 실거래 비용으로 본전 안팎 또는 손실.

### 김프 ↔ USDT 웃돈 (`overlap.js`, 2024~ 김프 1,209건)
- 김프 진입 순간 USDT 웃돈 z < −2 인 경우 9%, z < −1 은 33%. 이 구간 김프 거래는 거래당 −0.2~−0.27%(승률 44~46%), z ≥ 0 은 +0.11%(61%).
- 보유 중 김프 변화 +0.159%p = USDT 웃돈 몫 −0.053%p + 코인 고유 몫 +0.212%p → 김프 이익은 코인 고유 괴리에서 나온다.
- «USDT 웃돈 z < 0 이면 김프 진입 안 함»(`uz=0`): 2024~ 연 −1.3% → +1.7%(스프레드 절반), −7.4% → −2.3%(스프레드 전부).

## 한계
- 빗썸은 상장폐지 종목 과거 자료를 주지 않는다(LUNA·FTT 404) → 살아남은 종목만, 결과가 좋게 나온다.
- 스프레드·호가 깊이는 2026-10-15 중앙값을 과거 전체에 썼다. 과거 스프레드가 더 넓었다면 결과는 더 나쁘다.
- 김프 환율은 봇과 같은 하루 1회 값(전날 종가). 체결은 판단 5분 뒤 봉 종가 ± 스프레드.
