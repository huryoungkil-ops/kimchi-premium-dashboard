# 김프레이더

김치 프리미엄 페이퍼 트레이딩 봇의 공개 대시보드 (정적 페이지, Vercel 배포용).
상단 탭으로 김치프리미엄 · 터틀 트레이딩 · 제2의 루나 세 전략을 보여줍니다.

## 봇은 카페24에서 돕니다 (2026-10-05~)

봇은 이 저장소에 없습니다. 카페24 서버에서 돌면서 결과만 이 저장소의 브랜치에 JSON으로 올립니다.
**n8n은 2026-10-07에 정리했고 더 이상 쓰지 않습니다.**

| 전략 | 브랜치 / 파일 | 올리는 주기 |
|---|---|---|
| 김치프리미엄 | `paper-kimchi` / `kimchi.json` | 5분 |
| 터틀 트레이딩 | `paper-turtle` / `turtle.json` | 15분 |
| 제2의 루나 | `paper-luna` / `luna.json` | 15분 |

`kimchi.json`에는 최근 회차 시각(`lastCycle`), 누적 성적(`stats`), 종목별 김프(`coins`),
스캔한 종목과 거래 대상 여부(`universe`), 보유 포지션(`live`), 전체 매매 기록(`trades`)이 들어 있습니다.
**기록의 기준은 이 파일입니다.**

## 페이지 구성

- `index.html` 하나로 구성된 정적 페이지입니다. 별도 빌드 과정이 없습니다.
- 페이지를 열 때 위 JSON을 `raw.githubusercontent.com`에서 읽어 타일·표·보유 포지션을 다시 그립니다.
  읽기에 실패하면 HTML에 박혀 있는 마지막 스냅샷이 그대로 보입니다.
- «거래소별 잔액» 섹션은 `ledger/`(원장 계산·설정·옛 거래 환율 백필)와 `kimchi.json`의 매매 기록으로
  브라우저에서 직접 계산합니다. 검증: `node ledger/check.js [환율]`.
  리밸런싱(가상 이체)은 `ledger/config.json`의 `transfers`에 한 줄 추가합니다.
- JSON은 `main`이 아닌 브랜치에 올라오므로 5분마다 커밋돼도 Vercel 배포는 생기지 않습니다.

## 폴더

| 경로 | 내용 |
|---|---|
| `index.html` | 대시보드 |
| `ledger/` | 거래소별 잔액 원장 |
| `backtest/` | 김프 전략 백테스트와 측정 기록. `lib5m.js`의 `LIVE_PARAMS`가 봇 설정의 기준 |
| `backup/` | n8n 시절(2026-09-05 ~ 10-05)의 기록 보관소. 더 이상 갱신되지 않습니다 |

## 확인 안 된 것

- 카페24 봇의 코드와 설정이 어디에 보관돼 있는지는 이 저장소에 적혀 있지 않습니다.
- 5분마다 찍는 김프 이력을 카페24 봇이 따로 쌓고 있는지 확인하지 못했습니다. `kimchi.json`에는
  최근 회차 값만 있고 이력은 없습니다. 코빗 5분봉은 약 170일치만 제공되므로, 이력을 남기지 않으면
  그보다 오래된 코빗 기준 김프는 나중에 다시 만들 수 없습니다 (`backup/README.md` 참조).
