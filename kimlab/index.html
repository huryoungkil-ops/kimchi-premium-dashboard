장부 7개 — BASE 와 비교

모두 같은 5분 회차·같은 호가를 봅니다. «BASE 대비»는 지금 잔액의 차이(달러)입니다. 잔액 = 원화 다리(지금 환율로 달러 환산) + 선물 다리(미실현 포함) + 받은 펀딩 − 수수료. 판정 칸은 BASE 청산 30건과 8주가 모두 찬 뒤에야 «진행 중»에서 바뀝니다.

실전 봇과 BASE — 페이퍼와 실전의 차이

실험실이 시작된 뒤 실전 김프 봇이 청산한 거래와, 같은 코인을 BASE 가 같은 무렵(진입 시각 ±1시간) 거래한 기록을 나란히 놓습니다. BASE 는 호가를 14초 늦게 보고, 주문 지연·부분체결이 없다고 칩니다. 실전 손익에는 펀딩이 빠져 있어 BASE 도 펀딩을 뺀 값으로 견줍니다.

코인실전 진입 → 청산 (KST)실전 순손익BASE 진입 → 청산 (KST)BASE 순손익 (펀딩 제외)차이

메이커 섀도 — 지정가로 샀다면 체결됐을까 (기록만)

BASE 가 진입할 때마다 «그 순간 빗썸 최우선 매수호가에 같은 수량 지정가»를 냈다고 치고, 이후 빗썸 체결 기록(1분마다)으로 체결 여부를 봅니다. 같은 가격에서는 먼저 줄 선 물량이 다 체결돼야 내 차례로 칩니다. 김프 개선 = 시장가 진입 김프 − (지정가 ÷ 체결한 분의 Binance 1분봉 종가). 손익 주장은 하지 않습니다 — 연구 실측(10-17, 1시간 남짓)은 5분 46% · 30분 85% 체결, 체결분 +0.11%p 였습니다.

변형 여섯 개 — 무엇을 바꿨고, 연구에서는 어땠나

숫자는 5분봉 백테스트의 검증 구간(2024-01 ~ 2026-10)에서 같은 엔진의 기준(지금 실전 규칙: 월 +$63, 샤프 1.08, 최대낙폭 −3.0%) 대비 차이입니다. 상장폐지 종목이 빠져 있고(좋게 나옴), 스프레드는 2026-10 값을 과거 전체에 썼습니다. 기준 규칙 자체도 이 검증 구간을 보고 고른 것이라 숫자가 깨끗하지 않습니다.

➕ ADD15 · 물타기 한 번 사후 관찰

들고 있는 코인의 김프가 첫 진입 김프보다 1.5σ(첫 진입 때 잰 σ) 더 떨어지면 같은 크기로 한 번 더 산다. 실전과 같은 관문(기대이익 ≥ 3 × 비용)·USDT 필터·자리·예산을 그대로 거친다. 청산은 두 조각을 함께, 평소 신호(+0.5σ)로.

검증 +$533 (2.8년 합, +26%) · 샤프 1.05 → 1.28 · 최대낙폭 같음 · P(더 좋음) 0.99

⚠️ 미리 정한 주 설계(«지금 평균 − 2.5σ»)는 검증에서 −$88로 실패했고, 이 규칙은 그 뒤에 본 것입니다. 이익이 몇 사건에 몰려 있습니다 — 검증 34개월 중 21개월은 차이 ≈ 0, 2026-09 INJ 한 달이 +$353. 그 달을 빼면 +$180.

🎯 EXIT075 · 청산선 +0.75σ 부수 관찰

청산선을 «평균 + 0.5σ»에서 «평균 + 0.75σ»로 조금 넓혀, 김프가 평균을 더 넘어설 때까지 기다린다. 나머지는 실전과 같다.

검증 +$425 (2.8년 합) · P 0.98 · 2024·25·26년 모두 플러스 · 개발 구간 +$186

⚠️ 물타기 연구 중에 «덤으로» 본 결과라 따로 확인이 필요합니다. 개발 구간에서 고른 값은 +1σ 였고, +0.75σ 는 검증을 보고 고른 셈입니다.

💸 FUND · 펀딩 반영 확신 낮음

선물 숏은 8시간(또는 1·4시간)마다 펀딩을 주고받는다. 최근 3회 펀딩으로 «32시간 들고 있으면 받을 펀딩»을 기대이익에 더하고, 숏이 펀딩을 내는 종목(직전 펀딩 8시간 환산 −0.01% 미만)은 건너뛴다.

검증 월 +$13 [90% 구간 −6, +41] · 최대낙폭 −3.0 → −2.2% · 개발 월 +$32

펀딩 자체는 작아서(알트 하루 0.03% 안팎) 돈보다 «해외에서 숏이 몰린 종목 피하기» 효과로 보입니다. 구현이 가장 쉽습니다.

💵 IDLE_USDT · 놀고 있는 원화 확신 중간

김프 봇은 빗썸 원화의 평균 84%를 놀린다. 그 원화로 USDT 웃돈 전략(웃돈이 14일 평균 −2σ 아래면 USDT 매수, +0.5σ 위면 매도, 편도 0.09%)을 함께 돌린다. 김프 진입에 원화가 모자라면 그 순간 USDT 를 판다(비용 포함).

검증 월 +$71 · 합산 샤프 1.07 → 1.83 · 최대낙폭 그대로 · 김프와 상관 0.01

빗썸 USDT 시장이 2023-12에 생겨 개발 구간이 없습니다. 김프 봇이 USDT 웃돈이 낮을 때(z<0) 진입을 막는 바로 그때 USDT 를 사는 구조라 궁합은 좋습니다.

🏦 UPBIT · 업비트 추가 확신 낮음

업비트 원화 시세로도 같은 신호를 계산해, 두 거래소 중 순기대이익이 큰 쪽에서 산다. 원화는 두 거래소에 반씩, 거래소별 보유 한도는 예산의 절반($4,000). 업비트 수수료 0.05%.

검증(2025-04~) 월 +$32 [90% 구간 −22, +100] · 개발(2024-01~2025-03) +$33 · 샤프 1.22 → 1.50

업비트 김프 이력이 없어 시작 후 약 6일(7일 창의 80%)이 지나야 업비트 쪽 진입이 시작됩니다. 실전이라면 업비트 계정·원화 이체 운영 부담이 있습니다.

🧩 COMBO · 모두 합침 탐색

FUND + ADD15 + EXIT075 + IDLE_USDT + UPBIT. 각각의 효과가 서로 더해지는지 보는 장부.

연구에서는 FUND + UPBIT 조합만 탐색: 월 +$68 [+13, +140], 샤프 2.46

판정은 하지만, 개별 변형이 모두 기각인데 COMBO 만 좋으면 실전 후보로 올리지 않습니다.

🚦 NOUZ · USDT 웃돈 필터 끔 10-18 추가

실전 규칙에서 «USDT 웃돈 z < −0.5이면 새 진입 안 함»(10-19 전 기준 0)만 뺀 장부. 필터가 정말 도움이 되는지 오늘 이후 시세로 확인합니다. 10-18부터 시작해, 같은 기간의 BASE와 비교합니다.

근거 연구(2024~ 김프 1,209건): 필터를 켜면 연 −1.3% → +1.7%(스프레드 절반), −7.4% → −2.3%(스프레드 전부). z ≥ 0 진입은 거래당 +0.11%·승률 61%, z < −1 은 −0.2~−0.27%·44~46%

NOUZ가 BASE보다 확실히 낫다(P ≥ 0.9, 낙폭 1%p 이내)고 나오면 실전에서 필터를 끕니다. NOUZ가 BASE 이하면 필터 유지 — 사용자 결정(10-18)으로 미리 정한 규칙입니다.

BASE
실전 서비스 설정 파일에서 규칙 값을 읽어 실전 봇과 같은 판단 코드를 그대로 씁니다: 7일 평균·σ, 평균 −1.5σ 아래 진입, +0.5σ 위 청산, USDT 웃돈 z < 0 이면 새 진입 없음, 기대이익 ≥ 3 × (왕복 비용 0.18% + 스프레드), 크기 = 자산 10%(호가 깊이 30% 상한, 최소 $500), 자리 6, 보유 명목 $8,000, 2일·5일·해외가 +50% 강제청산, 하루 실현손실 $20 넘으면 그날 진입 중단. 거래 대상 종목도 실전 스캐너 목록 그대로, 빗썸 김프도 실전 봇이 같은 회차에 잰 값 그대로(실전이 멈추면 직접 잼)

안 하는 것

1분 판정·양방향
1분마다 판단 +$124/월(표본 작음, 확신 낮음), 김프 위쪽 이탈도 먹는 양방향은 자본 $20,000 추가 필요 — 이번 실험실에는 넣지 않음
판정 (실행 전 고정)
BASE 청산 30건 + 시작 8주 중 늦은 때. 장부 − BASE 달러 손익 > 0 이고, 일 손익 차이를 7일 블록으로 1만 번 다시 뽑은 P(더 좋음) ≥ 0.9 이고, 최대낙폭이 BASE 보다 1%p 넘게 나쁘지 않으면 «실전 후보»(사람이 승인). 손익 차이 ≤ 0 이면 «기각». 그 사이면 «계속» — 8주 뒤 한 번 더, 그때도 아니면 기각
다중 비교
여섯 개를 한꺼번에 보니 하나쯤은 우연히 통과할 수 있습니다(각 10%씩이면 하나 이상 약 47%). 그래서 후보 = 곧바로 적용이 아니라 검토 시작입니다
