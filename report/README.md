# 아침 상태 보고 차트 (견본)

매일 07:40 Discord 상태 보고에 붙일 차트의 **견본**입니다. 아직 봇에 연결되지 않았습니다.

![견본](sample.png)

## 무엇을 그리나

보유 중인 종목 전부와, 진입선에 가장 가까운 후보 3종목을 한 장에 그립니다. 기간은 최근 72시간입니다.

| 선 | 뜻 |
|---|---|
| 파란 선 | 김치 프리미엄 (5분 간격) |
| 굵은 주황 선 | 진입선 — 3일 평균 − 2σ. 봇이 실제로 쓰는 선 |
| 가는 주황 점선 | −2.5σ, −3σ. 얼마나 깊이 들어왔는지 보는 눈금이며 봇 동작과는 무관 |
| 회색 점선 | 3일 평균 |
| 초록 점선 | 청산선 — 3일 평균 + 0.25σ |
| 빨간 ▼ | 진입 시점과 진입 김프 (보유 종목만) |

후보 종목 제목 옆의 «근접도»는 3일 평균을 0%, 진입선을 100%로 본 현재 위치입니다.

## 후보 3종목을 고르는 기준

현재 김프가 진입선까지 몇 σ 남았는지를 재서 짧은 순으로 고릅니다. `kimchi.json`의 `universe`에서
`tradable`인 종목만 대상으로 하고, 이미 보유 중인 종목은 뺍니다.

- 카페24 봇이 5분 김프 이력을 72시간 넘게 갖고 있는지 확인하지 못했습니다. 차트는 3일 평균과 σ를
  시점마다 다시 계산하므로 실제로는 6일치가 필요합니다. 3일치만 있으면 선을 «현재 값 기준 수평선»으로
  바꿔 그려야 합니다.

  실제 진입은 선보다 조금 아래에서 일어납니다. 순이익 배수(`EDGE_MULTIPLE`) 조건도 차트에는 없습니다.
